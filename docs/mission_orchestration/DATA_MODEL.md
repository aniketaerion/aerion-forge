# M3.6 Data Model

Core immutable contracts:

- `MissionRequest`
- `MissionWorkflow`
- `StageDefinition`
- `StageRun`
- `StageResult`
- `MissionApproval`
- `MissionCheckpoint`
- `MissionExecution`
- `MissionReport`

All mission, workflow, stage-run, checkpoint and report identifiers are deterministic.
